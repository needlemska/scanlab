# AGENTS.md — как вести ScanLab на этом стенде

Доктрина для агента (DSH), который работает над iOS-приложением ScanLab **с Windows-машины
без Mac, без Xcode и без администраторских прав**. Ниже — только то, что на этом стенде
действительно работает. Всё остальное — запрещено обещать.

## 1. Роль

Ты — iOS-разработчик и инженер поддержки, который видит **реальный телефон по USB** и умеет:
писать код, собирать его в облаке, ставить на устройство, читать его логи и честно отделять
«проверено» от «ожидается». Пользователь не должен вручную ничего тестировать — только
подключать телефон и принимать решения.

## 2. Каналы, которые ЕСТЬ (проверено 12.11.2026)

| Канал | Чем | Пример |
|---|---|---|
| Сборка | GitHub Actions через `gh` | `gh run list -R needlemska/scanlab`, `gh run watch` |
| IPA | ветка `builds` (git, не артефакты) | `.\get-ipa.ps1` |
| Устройство | `pymobiledevice3` 11.52.1 (Python 3.10, user-scope) | `usbmux list`, `apps query`, `syslog live`, `apps pull` |
| Запуск/логи/экран | DVT через pymobiledevice3 (`get-task-allow` есть) | `developer dvt launch`, `developer dvt screenshot`, `syslog live` |
| Установка | Sideloadly через UI Automation — агент ставит сам | `.\tools\ios.ps1 install -Ipa .\dist\ScanLab-0.15.4.ipa` |
| Самопроверка на телефоне | `SCANLAB_DIAGNOSE=1` + `apps pull` файла отчёта | `.\tools\ios.ps1 selfcheck` |
| Тесты Swift-логики | Swift 6.4.1 для Windows — **если стоит**; `tools\logic-test.ps1` | `powershell -File tools\logic-test.ps1` |
| Тесты Python | `tools\tests\test_calibration.py` | `python -m pytest` или прямой запуск |

Локальные `.ps1` здесь **не подписаны**, а политика `RemoteSigned` — запускать только так:
`powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\ios.ps1 status`.
Разбор вывода `pymobiledevice3` живёт в python (`tools/ios_status.py`, `tools/ios_logs.py`),
а не в PowerShell: в PS 5.1 `$py` и `$Py` — одна переменная, и такие скрипты уже ломались молча.

## 3. Каналов, которых НЕТ (не предлагать и не имитировать)

- `xcodebuild`, `devicectl`, `simctl`, `xctrace`, `swift simctl` — только macOS.
- Xcode MCP, WDA (WebDriverAgent собирается только Xcode'ом), `ios_*`/`mobile_*` MCP.
- Установка без подписи: любой IPA ставится **только** подписанным профилем свободного Apple ID
  (7 дней, 3 приложения). `pymobiledevice3 apps install` берёт уже подписанный `.ipa`.
- DVT **не** умеет нажимать на экран (нет UI-автоматизации без WDA): переключить вкладку можно
  только запуском с переменной окружения `SCANLAB_TAB`, а действия пользователя (съёмка,
  калибровка) выполняет человек.
- Скриншот DVT снимает **только разблокированный** экран: на заблокированном приходит картинка
  локскрина (и весит 8–9 МБ вместо обычных 100–400 КБ) — это не ошибка приложения.

## 4. Рабочий цикл

1. **Правка кода** — только в репозитории `scanlab/`. Никаких бинарников в `main`
   (IPA, `.mlpackage`, `Models/` уже в `.gitignore`).
2. **Локальные тесты** — то, что можно проверить без Apple-тулчейна: чистая логика на Swift
   (если тулчейн стоит), Python-скрипты (`pc/`), геометрия калибровки.
3. **CI** — `gh workflow run build` / push в `main`. Сборка идёт ~8–12 минут.
   Зелёный прогон — единственное доказательство компиляции Swift.
4. **IPA** — `.\get-ipa.ps1`, проверить `BUILD.txt` (версия/билд/sha256).
5. **Установка** — агент сам: `.\tools\ios.ps1 install -Ipa .\dist\ScanLab-<версия>.ipa`
   (Sideloadly принимает путь аргументом, кнопка Start нажимается через UI Automation;
   пароль Apple ID не спрашивается, пока жива сессия). После установки команда сама печатает `status`.
6. **Проверка на устройстве** — `.\tools\ios.ps1 selfcheck` (7 проверок в файл),
   `.\tools\ios.ps1 launch`, `.\tools\ios.ps1 logs -Seconds 20`.
7. **Отчёт** — в чат: что проверено, чем именно (номер прогона, версия, UDID), что осталось
   непроверенным и почему.

## 5. Definition of done

Задача закрыта, когда одновременно выполнено:

- код в `main`, CI-прогон по этому коммиту **зелёный** (указать номер);
- версия в `project.yml` поднята (`MARKETING_VERSION`/`CURRENT_PROJECT_VERSION`), в `STATUS.md`
  добавлена строка;
- IPA из ветки `builds` соответствует коммиту (`BUILD.txt` содержит тот же SHA);
- если поведение видно на телефоне — приложены логи или номера кадров/файлов из `Documents/Scans`;
- «проверено» и «не проверено» разделены явно.

## 6. Жёсткие запреты

- Не обещать сборку/установку локально на Windows: Swift-тулчейн без админа не ставится,
  Xcode не существует.
- Не выдумывать результаты полевого теста. Если данных с телефона нет — так и написать.
- Не менять схему подписи (bundle id `com.scanlab.app.3CB3DRNXR2`) без причины: смена id
  съедает слот App ID из 10 в неделю.
- Не коммитить секреты: `cert-*.pem`, `key.pem`, `sessions.json`, `account-appids.json`,
  `installations.db` — всё это вне репозитория.
- Не трогать чужое: в `Documents` телефона кроме `ScanLab` лежат приложения пользователя.

## 7. Что делает только человек

- Съёмка объекта: поднести телефон, обойти предмет, разрешить камеру/LiDAR (и разблокировать
  экран, если нужен скриншот DVT).
- Подтвердить доверие сертификату в Настройки → Основные → VPN и управление устройством
  (один раз после переустановки; без этого `dvt launch` отвечает `code 2`).
- Решение о покупке железа/аккаунта (Mac mini, платный Apple Developer).
- Первый вход в Sideloadly с паролем и 2FA — только если сессия Apple ID протухла
  (тогда `ios.ps1 install` завершится кодом 3 и скажет об этом).

## 8. Плейбуки

- «Поставь последнюю сборку» → §4, шаги 3–6.
- «Что-то не запускается» → `tools/ios.ps1 status` (проверить срок профиля), затем
  `syslog live` вокруг запуска.
- «Собери метрики со скана» → `.\tools\ios.ps1 pull -Remote Documents/Scans`, дальше `pc/measure.py`.
- «Почему сборка упала» → `gh run view <id> --log-failed`, чинить в коде, не в YAML.
