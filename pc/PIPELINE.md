# Пайплайн на ПК: из кадров iPhone — в точную модель для 3D-печати

Железо: RTX 5080 + 4080S, Windows. Всё считается локально, без облака.
Файлы приходят из ScanLab одним ZIP: `img_NNN.jpg`, `img_NNN_depth.f32`, `shots.json`.

---

## 0. Честная граница возможностей

| Источник | Что даёт | Точность | Для печати |
|---|---|---|---|
| LiDAR iPhone (ARKit mesh) | форма, метры «из коробки» | ~1–2 см | черновик, габариты, посадка |
| Фотограмметрия + масштабная метка | реальная геометрия | 0.1–0.5 мм на объекте 10–30 см | **да, размеры отсюда** |
| Генеративный ИИ (TRELLIS, Hunyuan3D, TripoSR) | красивая модель по 1–4 фото | «на глаз», не метрическая | нет (только декор/заплатки) |

Главная ошибка новичка — мерить генеративную модель. Она правдоподобна и
бесполезна как чертёж: масштаб и пропорции не гарантированы.

---

## 1. Подготовка съёмки (это 80% результата)

- **Масштабная метка обязательна.** Лист с ArUco/AprilTag, напечатанный на принтере
  с известной стороной (например ровно 100.0 мм между центрами двух меток), или
  металлическая линейка. Кладётся рядом с объектом, видна на 3+ кадрах с разных сторон.
- Матовый объект: блестящее и чёрное — матовый спрей или пудра. Стекло и прозрачное — не сканируется.
- Свет: рассеянный, без прямого солнца и без жёстких теней; объект неподвижен, фон текстурный (не белая стена).
- Камера: ISO 100, выдержка по свету, фокус и ББ зафиксированы (всё это есть во вкладке «Фото»).
- Кадры: 45° шаг по кольцу, 2–3 высоты, перекрытие 70–80%, дистанция — объект занимает 60–70% кадра. Итого 60–120 кадров.

---

## 2. Реконструкция: RealityCapture (основной вариант)

Бесплатен для личного использования (доход < $1M/год), использует CUDA → на 5080
считает 100 кадров за минуты.

1. `Workflow → Add Images` — все JPEG.
2. `Align Images` — получить камеры. Если < 90% выровнялось, добавить кадры, а не крутить настройки.
3. **Масштаб:** `Tools → Scale Bars` (или контрольные точки) → указать две точки на
   метке → ввести реальное расстояние, например `100.0 mm`. Без этого шага модель
   безразмерная (в условных единицах).
4. `Reconstruct → Normal Detail` (или High для мелких деталей).
5. `Simplify` до 300–800k треугольников, `Clean` — убрать фон.
6. `Export → OBJ` (+ текстура) или сразу `STL` для печати.

Внутри RealityCapture есть инструмент измерения: `Tools → Measure` — расстояния,
диаметры, углы прямо по модели. Для большинства задач «измерить деталь» этого достаточно.

Альтернатива без лицензионных вопросов: **Meshroom** (AliceVision) — бесплатный,
но без CUDA и медленнее; масштаб задаётся через `Meshing → Scale` по контрольным точкам.

Ещё вариант: **COLMAP** (dense) + OpenMVS — полностью открытый, точный, но ручной.

## 3. ИИ-обработка на 5080 (что реально помогает)

| Задача | Инструмент | Зачем |
|---|---|---|
| Убрать фон | **SAM 2** (авто-маски) | фотограмметрия не «приклеивает» стол и фон |
| Контроль глубины | **Depth Anything V2** / **Metric3D v2** | проверка и заполнение провалов LiDAR |
| Заделка дыр, watertight | **PyMeshFix**, **Open3D** | STL без дыр, иначе слайсер ругается |
| Ретопология | **InstantMeshes** | чистые квады для правки в Blender |
| Недостающие части | **TRELLIS** / **Hunyuan3D 2.x** | только декор; размеры не брать |

Порядок: маски → реконструкция → чистка → watertight → измерение → экспорт STL.

## 4. Измерение и проверка под печать

```powershell
pip install open3d numpy
python pc/measure.py ScanLab.zip
python pc/measure.py model.obj --units mm      # если координаты уже в миллиметрах
python pc/measure.py model.stl --scale 0.5     # если модель почему-то вдвое больше
```

Скрипт покажет габариты в мм, объём, watertight, число компонент и сохранит
`model_mm.stl` (масштаб уже в миллиметрах). Объём считается по теореме о дивергенции,
поэтому на выпуклых моделях он занижается на доли процента — для проверки «пролезет ли
в камеру» этого хватает.

Проверено на эталонах: куб 100 мм → `100.0 x 100.0 x 100.0`, объём `1000.0 cm³`;
сфера R50 (24×48 сегментов) → `100.0 x 100.0 x 100.0`, объём `510.98 cm³`
(у идеальной сферы 523.6 — тесселяция занижает).

Если вход — один файл `.obj`, скрипт берёт именно его; если папка или ZIP — самый
большой меш внутри, пропуская собственную папку `--out`.

Ручные инструменты: **CloudCompare** (расстояния, сечения, сравнение с эталоном),
**Blender + MeasureIt**, **RealityCapture Measure**.

Перед слайсером:

- [ ] габарит совпадает с ожидаемым (проверка масштаба);
- [ ] модель watertight, без дыр и «волосков»;
- [ ] толщина стенок ≥ 1.2 мм (0.4 мм сопло × 3);
- [ ] нет самопересечений (иначе слайсер сделает мусор);
- [ ] плоское основание и правильная ориентация;
- [ ] допуск на посадку: +0.2 мм в отверстиях, −0.1 мм на валах.

## 5. Куда класть результаты

`pc/out/<имя>/` — `model.obj`, `texture.jpg`, `model_mm.stl`, `measure.json`.
Модели и кадры — на быстрый NVMe: фотограмметрия любит IO.
