# ScanLab — свой LiDAR + фотограмметрический сканер для iPhone

Приложение под iPhone 15 Pro Max, собирается **без Mac** (GitHub Actions), ставится
**бесплатным Apple ID** (Sideloadly). Никакого App Store, никаких подписок.

Что уже есть в v0.15.2:

| Вкладка | Что делает | Результат |
|---|---|---|
| **LiDAR** | ARKit-меш в реальном времени, статистика, пауза/продолжение, линейка, калибровка по эталону в кадре | `mesh.obj` (метры) + `mesh.stl` + `meta.json` → ZIP |
| **Фото** | Ручная ISO/выдержка, фиксация ББ и фокуса, серия кадров, глубина LiDAR, обход по секторам | `img_NNN.jpg`, `img_NNN_depth.f32`, `shots.json` (интринсики) → ZIP |
| **Сканы** | Список наборов, тип, размер, удаление, шаринг, Wi-Fi-выгрузка | ZIP через AirDrop / «Файлы» / HTTP |
| **Тест** | Самопроверка на телефоне: подпись, запись, место, ZIP, возможности, «умный габарит», математика эталона | текстовый отчёт в буфер и файлом |
| **Скан** | Главный режим: автосъёмка (кадр сам берётся на новом ракурсе), кольцо покрытия, подсказки, «Собрать 3D» | `img_NNN.jpg` + `shots.json` + `model.usdz` |
| **Скан → Apple 3D** | Запасной режим: Object Capture-сессия (iOS 17), когда нужен его меш и USDZ | `model.usdz` с текстурами |

Каждый архив сразу лежит в `Documents/Scans/` и виден в приложении «Файлы» →
«На iPhone» → «ScanLab». Переподпись приложения данные не трогает.

## 1. Сборка (один раз, 10 минут)

Нужен только аккаунт GitHub. Mac не нужен.

```powershell
cd scanlab
git init -b main
git add .
git commit -m "ScanLab v0.1: LiDAR mesh + pro photo capture"
```

Создайте **публичный** репозиторий `scanlab` на github.com (публичный — macOS-минуты
бесплатны; приватному нужно ~200 минут в месяц).

```powershell
git remote add origin https://github.com/ВАШ_ЛОГИН/scanlab.git
git push -u origin main
```

Дальше автоматически: вкладка **Actions** → workflow `build-ipa` → через ~4–6 минут
внизу страницы сборки артефакт **`ScanLab-unsigned-ipa`**. Скачать, распаковать →
`ScanLab-unsigned.ipa`.

**Если страница артефактов не открывается** (у части провайдеров блокируются
`pipelines.githubusercontent.com` и `objects.githubusercontent.com`) — рядом с `main`
появится ветка `builds` с готовым IPA, а забрать его можно git-ом:

```powershell
.\get-ipa.ps1
```

Если сборка упала — пришлите лог, правим и пушим снова. Проект генерируется
XcodeGen из `project.yml`, так что `.xcodeproj` в репозитории не нужен.

## 1б. Тесты на компьютере, без телефона и без CI

Три уровня, от дешёвого к дорогому.

**1. Чистая Swift-логика — CI-джоб `check`.** `Core/ScanCoach.swift` и `Core/ReferenceRect.swift`
не тянут Apple-фреймворки, поэтому компилируются и на macOS-раннере, и (если стоит
Swift-тулчейн с [swift.org/download](https://www.swift.org/download/)) на Windows локально:

```powershell
powershell -File tools/logic-test.ps1        # Windows + swiftc
```

Скрипт сам находит `swiftc`, собирает `Core/ScanCoach.swift Core/ReferenceRect.swift tools/logic/main.swift`
и гоняет **34 проверки** (16 направлений обхода, пороги дистанции, потеря трекинга,
поправки эталона A4/карта/монета, отсев «A4 как карта» и квадрата). Секунды вместо
5–10 минут полного прогона в Actions.

**2. ПК-часть — Python, локально.** Масштаб по позам и по глубине LiDAR, поворотный стол,
разбор `images.txt`:

```powershell
$py = "C:\Users\lenov\AppData\Local\Programs\Python\Python310\python.exe"
$env:PYTHONIOENCODING = "utf-8"
& $py tools\tests\test_calibration.py        # 23 проверки
```

**3. Симулятор iOS** — единственный «эмулятор», доступный с Windows: workflow `simulator`
на macOS-раннере собирает приложение, ставит его в симулятор и снимает экран каждой
вкладки (подробности — `RUNBOOK.md` §7б).

Ограничение: всё, что тянет ARKit/UIKit/AVFoundation, локально не собирается
(на Windows нет модуля `simd` и Apple-фреймворков) — это проверяет CI. Поэтому
новую чистую логику стоит держать в файлах без импортов Apple, как `ScanCoach.swift`.

## 1в. Своя Core ML-модель: конвертация в CI

У `coremltools` нет колёс под Windows (только macOS и Linux), поэтому конвертация
живёт в Actions: вкладка **Actions** → workflow `convert-model` → **Run workflow**,
выбрать `mil` (проверка toolchain) или `torch` (настоящий путь PyTorch → Core ML).

Результат — `.mlpackage` в ветке `models`:

```powershell
git fetch origin models; git ls-tree -r --long FETCH_HEAD | Select-String mlpackage
```

В готовое приложение модель попадёт, когда её добавим в `project.yml` (папка
`Models/`), и компилятор Xcode на macOS-раннере сам сделает из неё `.mlmodelc`.
Пока модель не нужна: то, что мы реально используем, — системные API (Vision,
ARKit, `PhotogrammetrySession`), подробности в [AI.md](AI.md).

## 2. Установка на iPhone (бесплатный Apple ID)

Подписывает **Sideloadly**, iMazing — нет (он только ставит уже подписанный IPA
и даёт доступ к песочнице).

1. **Apple Devices** из Microsoft Store (даёт драйверы и `usbmuxd`). iTunes из Store тоже подойдёт.
2. **Sideloadly** с sideloadly.io.
3. На iPhone: *Настройки → Конфиденциальность и безопасность → Режим разработчика* → включить, перезагрузить. Пункт появляется после первого подключения к компьютеру.
4. Кабель, «Доверять этому компьютеру».
5. Sideloadly: перетащить `ScanLab-unsigned.ipa`, ввести свой Apple ID, **Start**. Спросит пароль и код 2FA — вводить обычный пароль Apple ID (app-specific password не нужен).
6. На iPhone: *Настройки → Основные → VPN и управление устройством → Разработчик … → Доверять*.
7. Запуск ScanLab.

Ограничения бесплатного аккаунта:

- подпись живёт **7 дней** — приложение перестанет запускаться, нужно повторить п.5;
- максимум 3 приложения и 10 App ID в неделю;
- при повторной установке «поверх» контейнер обычно сохраняется, но **гарантии нет** —
  поэтому всё важное сразу уходит в ZIP и в «Файлы»/iCloud.

Если Sideloadly ругается на установку: смените Bundle ID в его окне (например
`com.scanlab.app2`), проверьте режим разработчика и что телефон разблокирован.

Хочется без переподписи каждую неделю — платный аккаунт $99/год, ad-hoc профиль
на год, до 100 устройств. Код при этом не меняется.

## 3. Что делать после установки

**Лидар-скан объекта (быстро, ~1 см):** вкладка LiDAR → «Старт» → обходить объект
0.3–2 м, медленно, с нескольких высот → «Пауза» → «Экспорт» → «Отдать архив на ПК».
Пауза не сбрасывает сцену: «Продолжить» вернёт ту же систему координат.

**Калибровка (перед экспортом):** положить рядом лист A4 (или карту, или монету 25 мм) →
в строке «эталон» нажать иконку прицела → выбрать эталон. Vision найдёт прямоугольник,
глубина LiDAR даст его стороны, приложение покажет поправку. Ручной путь — тапнуть два
конца эталона линейкой и нажать «Калибровать»; поправка вне ×0.5…×2 отвергается, потому
что это промах тапами, а не ошибка LiDAR.

**Фотограмметрия (точно, до 0.1–0.5 мм):** вкладка Фото → зафиксировать фокус и ББ →
выставить ISO 100 / выдержку по свету → «Снять серию» 40–80 кадров, обходя объект
по кольцу с двух-трёх высот → «Отдать кадры на ПК» → `pc/PIPELINE.md`. Масштаб
подставляется сам: по глубине LiDAR (`pc/scale_from_depth.py`) или по позам ARKit
(`pc/scale_from_poses.py`), а `--fit-mm` остаётся ручным фолбэком.

**Автосъёмка с коучем:** вкладка Скан → режим «Авто» → «Старт»: кадр берётся сам,
когда камера пришла на новый ракурс, кольцо показывает покрытие, подсказки ведут
«отойдите/ближе/наклоните сверху» → «Собрать 3D».

Ключевое правило: **LiDAR даёт форму и метры, фотограмметрия — точность.
Размеры для печати берутся только с масштабированной фотограмметрии.**

## 4. Структура

```
scanlab/
├── project.yml                     # XcodeGen: цели, схемы, настройки
├── App/
│   ├── ScanLabApp.swift            # точка входа, 5 вкладок, SCANLAB_TAB для скриншотов
│   └── Info.plist                  # камера, файлы, только портрет
├── Core/
│   ├── Paths.swift                 # Documents/Scans, ScanRecord (тип по префиксу папки)
│   ├── ZipWriter.swift             # свой ZIP (STORE) — папка → один файл
│   ├── MeshExporter.swift          # ARMeshAnchor → OBJ/STL в мировых координатах
│   ├── SmartBoundingBox.swift      # габарит по осям предмета (OBB + обрезка стола)
│   ├── ScanCoach.swift             # ракурсы, покрытие, подсказки автосъёмки
│   ├── ReferenceRect.swift         # геометрия эталона: стороны, поправка, отсев
│   ├── ReferenceScanner.swift      # Vision-прямоугольник + глубина в углах
│   ├── Provisioning.swift          # срок подписи из embedded.mobileprovision
│   └── FileServer.swift            # HTTP-сервер: сканы по Wi-Fi, потоковая отдача ZIP
├── Features/
│   ├── MeshScan/                   # ARKit-сессия + ARView + экспорт + линейка + эталон
│   ├── ProCapture/                 # AVCapturePhotoOutput, серия, глубина, обход по кругу
│   ├── AutoScan/                   # автосъёмка с коучем
│   ├── ObjectCapture/              # Apple Object Capture + фотограмметрия на телефоне
│   ├── Photogram/                  # PhotogrammetrySession → model.usdz
│   ├── Diagnostics/                # самопроверка алгоритмов на устройстве
│   └── Library/                    # список, шаринг, удаление, сервер выгрузки
├── pc/                             # пайплайн на 5080/4080S
│   ├── measure.py                  # габариты, калибровка, --smart, --fit-mm
│   ├── photogrammetry.py           # COLMAP + маска + масштаб одной командой
│   ├── sfm_io.py                   # общий разбор COLMAP TXT (камеры/кадры/точки)
│   ├── scale_from_depth.py         # масштаб по глубине LiDAR
│   ├── scale_from_poses.py         # масштаб по позам ARKit (Umeyama + RANSAC)
│   └── turn_table_check.py         # шаг/ось поворотного стола
├── tools/
│   ├── ios.ps1, ios_status.py, ios_logs.py   # телефон по USB: статус, логи, выгрузка
│   ├── logic/, logic-test.ps1      # Swift-логика без телефона
│   └── tests/test_calibration.py   # ПК-математика: 23 проверки
└── .github/workflows/              # build.yml (IPA), check (тесты), simulator.yml
```

скана, «Собрать 3D» строит `model.usdz` на телефоне.
v0.12 — срок подписи: приложение читает `embedded.mobileprovision` и показывает, сколько
дней осталось до переподписи; отчёт диагностики сохраняется файлом в `Documents/Scans`.
v0.13 — bug hunt: глубина LiDAR реально включается (формат с `supportedDepthDataFormats`),

создаёт сессию, «обход объекта» считает секторы по знаку поворота.
v0.14 — режим «Авто»: кадр берётся сам, когда камера пришла на новый ракурс (≥15°),
кольцо покрытия из 16 направлений вокруг предмета (низ и строгий верх исключены),
подсказки «отойдите / подойдите / наклоните сверху / обойдите»; Apple Object Capture
остался вторым режимом той же вкладки.

глубину в его углах, поправка масштаба считается по площади и сразу применяется к
