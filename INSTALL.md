# Установка ScanLab на iPhone (бесплатный Apple ID)

Сборка лежит в репозитории: `https://github.com/needlemska/scanlab` → ветка `builds` → файл `ScanLab-unsigned.ipa`.
Локально скачивается скриптом `get-ipa.ps1` (в папке `scanlab/`).

Файл `ScanLab-unsigned.ipa` **не подписан** — его подписывает Sideloadly вашим Apple ID в момент установки.

## Быстрая проверка и запуск

В папке `scanlab/` лежит `install.ps1`: он проверяет IPA (размер, sha256, версию из Info.plist),
Sideloadly, службу Apple, видимость телефона по USB, запись сопряжения — и, если всё в порядке,
открывает Sideloadly с готовым IPA.

```powershell
# только диагностика (ничего не запускает)
powershell -ExecutionPolicy Bypass -File install.ps1 -Check

# проверка + запуск Sideloadly, затем ждать установку 10 минут
powershell -ExecutionPolicy Bypass -File install.ps1 -Watch
```


## Что уже готово

- IPA собран GitHub Actions, содержит `Payload/ScanLab.app/ScanLab` (arm64), `MinimumOSVersion 17.0`, `com.scanlab.app`.
- iPhone уже спарен с этим ПК (запись сопряжения `00008130-000A44C01443001C`, iPhone 15 Pro Max) — для установки его нужно подключить кабелем.
- Sideloadly 0.71.2: `%LOCALAPPDATA%\Sideloadly\sideloadly.exe`.
- Apple Devices + служба `Apple Mobile Device Service` работают.

## Шаги

1. **Кабель и доверие.** Подключить iPhone кабелем, разблокировать, нажать «Доверять этому компьютеру», ввести пароль экрана.
2. **Sideloadly.** Открыть `%LOCALAPPDATA%\Sideloadly\sideloadly.exe`.
   - В строке `IPA` — путь к `ScanLab-unsigned.ipa` (кнопка выбора файла).
   - В поле `Apple ID` — ваш Apple ID (тот, что на телефоне).
   - Пароль — **пароль приложения**, не обычный пароль аккаунта:
     appleid.apple.com → Вход и безопасность → Пароли приложений → создать «Sideloadly» → скопировать 16 символов.
   - Нажать **Start**. Sideloadly сам определит устройство, создаст App ID, сертификат и профиль.
3. **Двухфакторный код.** Если всплывёт запрос 2FA — ввести 6 цифр с телефона.
4. **Режим разработчика.** На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить → перезагрузка.
5. **Доверие сертификату.** Настройки → Основные → VPN и управление устройством → «Разработчик: <ваш Apple ID>» → Доверять.
6. Запустить **ScanLab** с домашнего экрана.

## Первые пять минут после запуска

1. Вкладка **«Тест»** → «Проверить» → «Скопировать отчёт». Все строки должны быть зелёными;
   если нет — отчёт покажет, что именно не так на этом железе.
2. Вкладка **«LiDAR»** → «Старт» → обойти коробку/деталь → «Экспорт». В папке скана появятся
   `mesh.obj`, `mesh.stl`, `meta.json` и ZIP.
3. Измерения: линейкой по двум точкам, потом «эталон, мм» → «Калибровать» (вкладка «LiDAR»),
   затем кнопка «Умный» — габарит по осям предмета.
4. Вкладка **«Сканы»** → значок Wi-Fi → на ПК `python pc/fetch.py --url http://<ip>:8080 --new-only`
   → `python pc/measure.py <папка> --smart`.

Полный протокол проверки точности — в `TESTING.md`.

## Сроки и ограничения бесплатного аккаунта

- Подпись живёт **7 дней**. После истечения приложение не запускается — повторить шаги 2–5 (данные в `Documents/Scans` сохраняются).
- Не больше **3** своих приложений и **10** App ID в неделю на аккаунт.
- Платный аккаунт ($99/год) даёт год подписи и ad-hoc профиль на 100 устройств — тот же IPA, другой способ подписи.

## Данные не теряются

Все сканы пишутся в `Documents/Scans/<scan-id>/`, приложение отдаёт папку в «Файлы» (UIFileSharingEnabled) и умеет шарить ZIP. Даже если подпись истекла, файлы доступны через «Файлы» и Sideloadly → Manage Apps → Browse.

## Если Sideloadly не установит

- `Unable to install` / ошибка подписи на iOS 27 — обновить Sideloadly до последней версии.
- `Maximum number of App IDs` — удалить старые приложения этого Apple ID или подождать неделю.
- Устройство не видно — перезапустить службу `Apple Mobile Device Service` и переподключить кабель (не через USB-хаб).
